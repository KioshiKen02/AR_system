# API Endpoints per Business Unit

This document provides the specific API URLs for each Business Unit, with the `bu_id` parameter pre-filled.

---

## UBAY SERVER

## Feedmill (ID: 19)
*   **Get Cash In Bank List**: `/api/cash-in-bank?bu_id=19`
*   **Get Latest Payment No**: `/api/getlatestpaymentno?bu_id=19`
*   **Insert Customer Ledger**: `/api/insertcustomerledger?bu_id=19`
*   **Update Customer Ledger**: `/api/updatecustomerledger?bu_id=19`
*   **Insert Payment**: `/api/insertpayment?bu_id=19`
*   **Get Customer Ledger List**: `/api/get-customerledger-list?bu_id=19&document_no=`
